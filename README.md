# The Evolution of Trust — Galvoro Capsule

This is a Galvoro fork of [The Evolution of Trust](https://ncase.me/trust/) by
Nicky Case, prepared as a PLAY_LEARN capsule for hosting on the Galvoro
platform.

## Changes from upstream

This is a near-verbatim fork. Gameplay, copy, art, animation, and audio are
unchanged. Edits are limited to changes required by the
[Galvoro Capsule Contribution Spec](https://galvoro.app/spec):

- External links (social-share, GitHub, Patreon, translations list, footnote
  references) converted to plain text or removed, since the Galvoro iframe
  sandbox does not allow popups or top-frame navigation.
- The Facebook / Twitter / Email share component (`js/lib/sharing.js`) and its
  DOM container removed.
- Patreon donation prompts removed.
- Footnote citations in `notes/` rewritten as plain-text scholarly references
  retaining the source attribution.
- `http://` upgraded to `https://` in social meta tags.
- `capsule.json` added with Galvoro metadata.

No game logic, simulation parameters, copy, art, audio, or layout was modified.
